FLIPBOOK MAJALAH OLAHRAGA

Cara membuka:
1. Ekstrak file ZIP ini ke sebuah folder.
2. Buka folder Flipbook_Majalah.
3. Klik dua kali index.html.
4. Flipbook akan terbuka di browser.

Fitur:
- Animasi membalik halaman
- Tombol sebelumnya/berikutnya
- Slider navigasi halaman
- Zoom dan fullscreen
- Navigasi keyboard dan swipe di layar sentuh

Catatan: Flipbook berjalan offline setelah ZIP diekstrak.
